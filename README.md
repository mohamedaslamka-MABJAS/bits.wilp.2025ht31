# bits.wilp.2025ht31
BITS WILP Student Portal is a personal course dashboard for M.Tech structure 2025 WILP students. Sign in with your WILP mail ID on links to open Drive folders for courses and electives, and review archived subjects. Built-in tools include a quick CGPA calculator, target SGPA planner, four mini games, and four switchable themes powered by MABJAS
